# JRA-VAN 活用ガイド — 課金を無駄にしないために

## 現状(2026-08-07)

**JRA-VANは未活用(利用率0%)。** JV-LinkがWindows専用のため、クラウド側の
自動運用(NAR収集・分析)には組み込めていない。中央競馬の攻略は
JRA-VANの活用が事実上の前提なので、ここが最大の伸びしろ。

## JRA-VANだけが持つ、戦略上決定的なデータ

| データ | 戦略上の意味 |
|---|---|
| **時系列オッズ**(最短10秒間隔) | 「購入時点オッズ」でのEV計算・バックテストに必須。公開ソースでは代替不可(docs/strategy.md §2.3: 投票の半分は締切前10分) |
| **調教・追い切り**(ウッド/坂路) | 市場が織り込みきれない可能性のある数少ない情報源(Benter型モデルの差別化特徴量) |
| 全レース蓄積(1986年〜) | モデル学習に必要な数千〜数万レースが即時に揃う |
| 馬・血統・騎手・調教師マスタ | 特徴量の土台 |

## 活用への3ステップ(あなたの作業は①だけ)

1. **Windows PCで一度だけ**: JV-Link をインストール→利用キー登録→
   `pip install pywin32` → 初回全量ダンプ:
   ```
   python scripts\jvlink_dump.py --dataspec RACE --from 20240101000000 --option 4
   git add data/jvraw && git commit -m "JRA-VAN RACE dump" && git push
   ```
2. **クラウド側(Claude)**: 届いた生データ(JV-Data形式)のパーサを実装し、
   store.py スキーマに統合。NARと同じ分析パイプライン(較正→モデル→
   結合→対数尤度判定)を中央に対して実行
3. **以後の日次運用**: Windows側は `--option 1 --from <前回時刻>` の差分
   ダンプをタスクスケジューラで自動化(週1でも可)。リアルタイム系
   (時系列オッズ)は運用フェーズで `JVRTOpen` 系に拡張

## 規約上の注意

- 取得データは**個人利用の範囲**で扱う(JRA-VAN利用規約)。
  リポジトリをprivateに維持し、生データの再配布・公開をしない
- 蓄積系の再取得は帯域負荷が大きいため、初回全量後は差分運用にする
