# 期待値ベース馬券戦略 — リサーチ統合ドキュメント

> 本ドキュメントは、多段の並列Web調査と**敵対的検証**(各主張につき独立の検証者3名が反証を試み、

## 1. 結論(エグゼクティブサマリー)

1. **単純な必勝法は存在しない。** JRA単勝市場の最終オッズはほぼ効率的であり(71,549レースの実証)、
   人気順位やオッズ帯だけに基づく機械的戦略で控除率20%超を跳ね返すエッジは無い。
2. **実証された唯一の道は Benter 型の情報優位戦略。** 独自の確率モデルを作り、その出力を
   市場オッズ由来の確率と**ロジット結合**して較正済み確率を得て、EVプラスの馬券だけを
   フラクショナル・ケリーで買う。香港で5年間の実運用プラス収支という一次証拠がある。
3. **控除率の選択自体が戦略。** 券種で払戻率は80%(単複)〜70%(WIN5)まで変わる。
   キャリーオーバー時のWIN5とJRA「スーパープレミアム」対象レースは実効還元率が構造的に上がる。
4. **エッジは連系券種で増幅される。** 「ベットが特殊(具体的)であるほどアドバンテージは大きい」
   (Benter)。単勝でEVマイナスの確率差でも、馬単・三連単に展開すると+16%级のEVになりうる。
   ただしHarville公式は素のままではバイアスがあり指数補正が必須。
5. **収益の上限は流動性が決める。** 無限資金でもレース売上の0.25〜0.5%程度が上限。
   地方競馬の小さいプールは「歪みが残りやすいが、賭けた瞬間に自分でオッズを潰す」二面性を持つ。
6. **税制が実質的な追加控除になる。** 通常の購入態様では外れ馬券は経費にならない(一時所得)。
   税引後で考えると、雑所得認定(網羅的・機械的・継続的な購入態様)の可否が収益性を左右する。

## 2. 市場構造(検証済み)

### 2.1 券種別払戻率 — JRA(2014年6月7日以降)

| 券種 | 払戻率 | 控除率 |
|---|---|---|
| 単勝・複勝 | 80.0% | 20.0% |
| 枠連・馬連・ワイド | 77.5% | 22.5% |
| 馬単・三連複 | 75.0% | 25.0% |
| 三連単 | 72.5% | 27.5% |
| WIN5 | 70.0% | 30.0% |

- 払戻総額は `(W + D/P) × R`(WIN5のみ `+ A/P`、A=キャリーオーバー額)。
  W=的中票への投票総額、D=それ以外、P=的中票数、R=払戻率。
- 出典: [JRA 馬券の種類と払戻率](https://www.jra.go.jp/kouza/baken/index.html)(逐語確認 3-0×2)

### 2.2 実効還元率を上げる構造的機会(検証済み 3-0×3)

1. **WIN5キャリーオーバー**: 的中者不在時は払戻対象総額が次回に繰り越され、
   当該回の実効還元率は70%を**数学的に**上回りうる(公式計算式から導出)。
2. **スーパープレミアム**: 対象レースは全賭式の払戻率が80.0%に設定される
   (三連単 72.5%→80%、WIN5 70%→80%)。恒久制度ではなくプロモーションであり
   対象レースは限定的だが、開催時は同じ予測力でもEVが大幅に改善する。
   出典: [JRAスーパープレミアム](https://www.jra.go.jp/kouza/superpremium/)
3. **特払い**: 的中者ゼロの場合(WIN5以外)は100円につき70〜80円が投票者全員に払い戻される。

### 2.3 市場効率性 — 何が確認され、何が棄却されたか

**検証済み:**
- JRA単勝市場の最終オッズは**ほぼ効率的**。1986〜2006年の全JRAレース71,549件で、歪みは
  古典的な favorite-longshot bias (FLB) パターンに従わず(最上位0.4%の超人気馬が過小評価、
  次の約10%が過大評価という複雑な形)、単純戦略で搾取できる規模ではない
  ([Mori & Hisakado 2009](https://arxiv.org/pdf/0911.3249)、3-0)。
- 北米市場ではFLBが頑健に存在する(1倍台の本命の期待リターン~85%、30倍超の大穴~63%)が、
  **日本・香港では証拠が混在**しており、欧米型FLBを前提にできない
  ([Green, Lee & Rothschild](https://www.stat.berkeley.edu/~aldous/157/Papers/Green.pdf) 他、3-0)。
  日本で歪みの証拠が最も強いのは**三連単等エキゾチック券種でのプロスペクト理論的な
  低確率過大重み付け**。
- **オッズの時間動態が決定的**: JRA単勝投票の約半分は締切前10分に投じられる。
  発走約168分前の中間段階では「強い馬が過小評価」のFLB状態にあり、終盤の資金流入で
  効率が回復する(非単調)。早い時刻のオッズでのEV計算は信頼できない
  ([Mori & Hisakado 2009](https://arxiv.org/pdf/0911.3249)、[2025年プレプリント
  arXiv:2503.16470](https://arxiv.org/pdf/2503.16470)、3-0)。

**棄却された通説(敵対的検証で反証):**
- ×「競馬市場には常にFLBがあり本命側が常に高期待値」(1-2で棄却 — 市場・券種・時代依存)
- ×「日本・香港にはFLBが無いと確定しており単勝はよく較正されている」(0-3で棄却 — 断定は過剰)
- ×「締切に近づくほど単調に効率化し最終オッズは真の勝率をほぼ正確に反映」(0-3で棄却 —
  収束は非単調で、本命側の収束は遅い)
- ×「控除率がある以上、全ての戦略が長期マイナス」(0-3で棄却 — 予測エッジがあれば反例が存在する。
  Benterが実例)

**実務含意**: オッズスナップショットの**時系列**(前日→当日朝→直前の変化)は特徴量として
価値がある可能性が高い。一方、最終オッズだけを見て「歪んだゾーン」を探す単純戦略は
JRAでは機能しない。

## 3. 実証された手法 — Benter 方式(全項目 3-0 で逐語確認)

出典: [Benter (1994) "Computer-Based Horse Race Handicapping and Wagering Systems"](https://www.semanticscholar.org/paper/2ea3ed4fa5ea9645614d76dd0a79201740949566)
(香港で5年間の実運用プラス収支を報告した一次文献。Bloomberg 2018年プロフィールでも裏付け)

### 3.1 パイプライン

```
過去データ → ① 多項ロジット等でファンダメンタル勝率モデル f_i
           → ② 市場確率 π_i とロジット結合: c_i ∝ f_i^α · π_i^β   ← src/keiba/blend.py
           → ③ 較正チェック(信頼度曲線)                          ← src/keiba/calibration.py
           → ④ 連系券種へ展開(Harville+指数補正 γ, δ)            ← src/keiba/harville.py
           → ⑤ EV>閾値の馬券のみフラクショナル・ケリーで購入       ← src/keiba/kelly.py
```

### 3.2 核心的知見

- **モデル単体の確率は使うな**: ファンダメンタルモデルの勝率推定は「公衆オッズと乖離する側で
  系統的に外れる」(実測はモデルよりも公衆寄り)。ロジット結合後はこのバイアスが消える。
  Benterのデータでは R²: 公衆単体 0.1218 / モデル単体 0.1245 / 結合 0.1396。
  **結合による尤度改善(ΔR²≈0.018)こそが収益性の実用指標**。改善がゼロなら賭けても勝てない。
- **エキゾチックほど有利**: 「ベットが特殊(具体的)であるほどアドバンテージは大きい」。
  単勝で期待リターン-10%の2頭の組でも、馬単相当では+16%になる実例。複勝・ワイドは
  確率差が薄まり(watered down)妙味が小さい。
- **Harville補正**: 素のHarville公式は人気薄の2・3着確率を過小評価する。2着分布を p^γ、
  3着分布を p^δ で正規化する補正が必須(香港データで γ=0.81、δ=0.65。**日本では要再推定**)。
- **フラクショナル・ケリー必須**: アドバンテージを2倍以上過大評価するとフルケリーは
  資本成長率がマイナスになる。フルケリーでは資産50%超のドローダウンが常態。1/2〜1/3以下を推奨。
- **流動性の壁**: 無限資金でも最大期待利益はレース売上の0.25〜0.5%(1.5%超はまずない)。
  立ち上げ期の現実的目標は売上の0.1〜0.2%。モデル開発には最低500〜1000レース分の
  全出走馬データが必要。

### 3.3 注意(caveat)

Benterの収益は自己報告であり監査済みP&Lは無い。数値は1986〜1993年の香港プール前提。
γ・δ・α・βは全てデータ固有パラメータで、日本市場では自前データで再推定が必要。

## 4. 日本特有の制度要因

### 4.1 税務(検証済み 3-0。詳細は [research/tax.md](research/tax.md))

- **最高裁平成29年12月15日判決**: 網羅的・機械的・継続的(ほぼ全レース・6年間)な購入態様の
  事案で、払戻金を**雑所得**と認定し外れ馬券の必要経費算入を認めた。
  出典: [国税庁](https://www.nta.go.jp/information/other/data/h30/keiba/index.htm)、裁判所HP(判例ID 87308)
- **通常の購入者は一時所得のまま**: 外れ馬券は経費にならない。設例(購入1,000万・払戻1,100万・
  実利益100万)では、一時所得なら課税所得算入425万円 → 限界税率30%で税負担約127.5万円となり
  **実利益を上回って税引後赤字**。雑所得なら算入100万円。
- 雑所得認定の境界(判例・裁決): ①機械的・定式的な購入方法 ②ほぼ全レース級の網羅性
  ③長期継続 ④恒常的な年間黒字 ⑤**個々の購入記録による客観的立証** — が全て必要。
  平成30年裁決では記録を全部示せなかったことが致命傷になった。
- 源泉徴収・支払調書は無いが、JRAは**100円あたり1,000万円以上の払戻を受けたネット投票会員の
  情報を国税当局に提供**している(協力要請ベース)。
- 戦略設計への含意: 系統的・継続的な購入設計は統計的利点と税務上の利点が一致する。
  ただしEVフィルタでレースを絞るほど「網羅性」が下がる緊張関係に注意。
  **購入記録の完全自動保存を最初から実装する**(モデル検証にも必須)。

### 4.2 地方競馬(NAR)の実態(検証済み。詳細は [research/nar-market.md](research/nar-market.md))

- **控除率はJRAより総じて不利**: 2頭系(枠連・馬連・ワイド)は75%(JRA 77.5%)、
  三連複72.5%(JRA 75%)。単勝・複勝80%、馬単75%、三連単72.5%は同率。
  例外: ホッカイドウのワイド80%(全国唯一)、高知ファイナルレースの三連単77%、
  ホッカイドウの三連系70%(全国最低)。
- **市場規模(令和6年度)**: NAR全体で売得金1兆1,287億円、ネット投票が90.7%。
  1レース平均売上は大井 約2億円 〜 金沢・ばんえい 約3,000万円台と5〜6倍以上の格差。
- **プール構成**: 三連単が売上の4〜5割、単勝は1割未満。小規模場の単勝プールは
  数百万円規模になりえて、**大口の単勝投票は自らオッズを大きく動かす**。
  流動性制約が最初に効くのは単勝・複勝系。
- **実質還元**: SPAT4プレミアムポイントで実効控除率が約0.5pt下がる。
  TCK(大井)スーパープレミアム対象レースは全式別80%。
- 結論: NARは「歪みが残りやすい可能性 × 賭け込めない・オッズ変動が大きい」の二面性。
  モデル検証の場としては有効だが、収益の絶対額は南関東(特に大井ナイター)以外では小さい。

### 4.3 自動化・データ取得の規約(検証済み。詳細は [research/automation-tos.md](research/automation-tos.md))

- JRA(即PAT等)・SPAT4・オッズパーク・楽天競馬のいずれも、**自動投票プログラムを名指しで
  禁止する規約条項は確認されなかった**。禁止は投票代行・商業目的利用・システム妨害・包括条項。
- JRAの公式スタンスは「連携ソフト投票は無保証」。一方で**JRA-VAN公式サイト自身が
  IPAT連携自動投票ソフトを対応ソフトとして掲載**しており、事実上容認されたエコシステム。
- データは JRA-VAN DataLab.(月2,090円、JV-Link=Windows専用、速報オッズ最短10秒間隔、
  時系列オッズあり)と地方競馬DATA(UmaConn)が第一選択。
  netkeibaはスクレイピング過多で予告なく通信制限(公式FAQ明記)。
- 過去の大量購入事例(UPRO 160億円、大阪外れ馬券事件 28.7億円)でも、自動投票を理由に
  JRAが口座停止した公表事例は未確認(税務摘発が主リスク)。

## 5. 実装ロードマップ

### Phase 0: データ基盤(まずここから)
1. データ収集: JRA-VAN DataLab等の公式データでレース結果・オッズ履歴を蓄積
   (詳細は [data-sources.md](data-sources.md))。**購入時点オッズの時系列スナップショット**が最重要。
2. 最低500〜1000レース(全出走馬分)を確保してからモデリング開始(Benterの下限)。

### Phase 1: 勝率モデルと結合(src/keiba が対応)
1. ベースライン: 市場確率そのもの(`ev.normalized_implied_probabilities`)。
2. ファンダメンタルモデル f_i を構築(多項ロジット or LightGBM+ソフトマックス)。
3. `blend.fit_blend_weights` で α, β を推定。**α が有意に正でなければ賭けない**
   (モデルに市場超の情報が無い)。ΔlogL の大きさを監視。
4. `calibration.reliability_table` で較正確認。`roi_by_bin` でEVビン別回収率を確認。

### Phase 2: バックテストと券種展開
1. `backtest.backtest_win_bets` で単勝EV閾値戦略を時系列検証
   (直前オッズ使用・時系列分割・購入インパクト考慮)。
2. `harville.fit_gamma` 等で γ, δ を日本データで推定し、馬単・三連単に展開。
   エキゾチック展開後のEVが単勝より増幅されるかを確認。
3. 合成オッズ(`ev.synthetic_odds`)で点数拡大の期待値悪化を管理。

### Phase 3: 小額実運用
1. 1/4ケリー(`kelly.kelly_exclusive_outcomes(fraction=0.25)`)以下で開始。
2. 締切直前(オッズ形成の最終盤)での購入を原則とする。
3. 全購入記録を保存(税務+モデル検証の両方のため)。
4. 実測回収率とバックテストの乖離を毎月レビュー。乖離が大きければ即停止して原因分析。

### 撤退基準(事前に決める)
- 結合モデルの ΔlogL(市場単体比)が検証期間で正を維持できない → 賭け停止
- 実運用の回収率がバックテスト予測の信頼区間を下回り続ける → 賭け停止
- ドローダウンが事前設定値(例: 資金の30%)に達する → 賭け停止・再検証

## 7. リスク開示

- 控除率20〜30%の市場で長期プラスは**例外的な達成**であり、ほとんどの参加者は敗れる。
- 本書の「検証済み」は「出典に照らして主張が正確」の意味であり、「利益を保証」ではない。
- Benterの数値は30年前の香港のものであり、現在の日本市場では市場参加者の高度化
  (AI予想の普及等)によりエッジはさらに薄い可能性が高い。
- 余剰資金の範囲で行い、撤退基準を先に決めること。
