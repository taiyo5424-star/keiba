# 馬券払戻金の課税 — 一時所得/雑所得の実務

調査日: 2026-07-18。国税庁・裁判所・国税不服審判所・会計検査院・JRAの一次資料を直接確認。
**税引後の期待値こそが最終的なEV**であり、系統的戦略の設計に直結する。

## 1. 一時所得と雑所得の違い(設例)

設例: 年間購入1,000万円・払戻1,100万円(うち当たり馬券の購入費200万円)→ 実利益100万円

| | 一時所得 | 雑所得 |
|---|---|---|
| 総収入 | 1,100万円 | 1,100万円 |
| 控除できる支出 | 当たり馬券分200万円のみ | 全購入費1,000万円 |
| 特別控除 | △50万円 | なし |
| 1/2課税 | あり | なし |
| **総所得への算入額** | **425万円** | **100万円** |

- 限界税率30%(所得税20%+住民税10%)なら一時所得の税負担は約127.5万円で、
  **実利益100万円を上回り税引後赤字**。雑所得なら約30万円。
- 外れ馬券800万円が経費にならないことが差の原因。
- 給与所得者は一時所得の算入額(1/2後)20万円以下なら所得税の確定申告不要
  (住民税申告は別途必要)。

出典: [国税庁タックスアンサーNo.1490](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shotoku/1490.htm)、
[国税庁「払戻金の支払を受けた方へ」PDF](https://www.nta.go.jp/publication/pamph/shotoku/kakuteishinkokukankei/koueikyougi/pdf/001.pdf)

## 2. 雑所得認定の要件(判例・裁決)

| 事例 | 結果 | ポイント |
|---|---|---|
| 最高裁 平成27年3月10日(大阪・自動購入ソフト) | **雑所得** | ソフト+独自条件で3年間に28.7億円購入・30.1億円払戻。期間・回数・頻度・利益の規模等を総合考慮 |
| 最高裁 平成29年12月15日(札幌) | **雑所得** | ソフト無しでも、定式化した購入パターンで6年間ほぼ全レース購入・毎年黒字 |
| 東京高裁 平成28年9月29日(最高裁上告不受理で確定) | 一時所得 | 長期大量購入でも、ノウハウ不明瞭・年単位の多額損失あり →「恒常的利益の期待」を否定 |
| 国税不服審判所 平成30年3月22日裁決 | 一時所得 | 年間約7割のレースを購入していても、①年ごとの損益変動大(赤字年あり)②利益の相当部分が偶発的なWIN5的中③**個々の購入記録の全部を示せず**網羅性を立証できず |

**現行の所得税基本通達34-1**(平成30年改正、[原文](https://www.nta.go.jp/law/tsutatsu/kihon/shotoku/04/08.htm)):
ソフト又は定式化した購入パターンにより、偶然性の影響を減殺するために年間を通じて
ほぼ全てのレースで購入するなど、**期間総体として回収率100%超が客観的に明らか**な場合に雑所得。
それ以外は一時所得。

**境界線のまとめ**: ①機械的・定式的な購入方法 ②ほぼ全レース級の網羅性 ③長期継続
④恒常的な年間黒字 ⑤その全ての客観的立証 — が揃って初めて雑所得。
**購入記録の完全保存(PAT履歴・口座履歴・条件設定の記録)が生命線**。

## 3. 実務上の重要事実

- **源泉徴収・支払調書は存在しない**(会計検査院平成29年度決算検査報告が明記)。
  平成27年に1口1,050万円以上の高額払戻531口・127億円超のうち申告は69件のみ、
  「その多くが申告されていない」と検査院が推計。
  出典: [会計検査院](https://report.jbaudit.go.jp/org/h29/2017-h29-0883-0.htm)
- **JRAは1発売単位(100円)あたり1,000万円以上の払戻を受けたネット投票会員の情報を
  国税当局に提供**(国税通則法74条の12に基づく協力要請ベース)。
  出典: [JRA公式](https://jra.jp/company/social/taxation/)
- 追徴事例: 大阪事件では当初、一時所得前提で実利益1.4億円に対し約5.7億円の課税
  (最高裁で雑所得認定され縮小)。芸人「じゃい」氏は雑所得申告が一時所得認定され
  「破産級」の追徴と公表(2022年)。
- 無申告は無申告加算税・重加算税・延滞税が上乗せ。

## 4. 戦略設計への含意

1. **税引後EVで設計する**: 一時所得のままでは、年間回収率100%超でも税引後マイナスになりうる。
   低頻度・高配当型(WIN5一撃など)は一時所得リスクと高額払戻の情報提供の両方に晒される。
2. **雑所得認定を狙う設計**は「網羅的・機械的・継続的・恒常的黒字・完全な記録」が要件。
   これはEVフィルタで賭けるレースを絞る戦略と緊張関係にある(絞ると網羅性が下がる)点に注意。
   認定は個別の事実認定であり、機械的購入でも争われるリスクは残る。
3. **記録保存を最初から自動化**: 全購入履歴(レースID・券種・買い目・金額・時刻・オッズ)と
   入出金履歴をDBに保存する。これはモデル検証にも税務にも必須。
4. 個別の税務判断は税理士・税務署に確認のこと。
