# 競馬予想 期待値実行メモ

このワークスペースは、動画「Codexで競馬予想してみた！サブエージェント×ブラウザユースで本気予想」を参考に、複数観点の調査を期待値計算に集約して買い/見送りを判断するための最小基盤です。

## 基本方針

1. 予想は「当たりそう」ではなく「市場オッズより過小評価されているか」で判断する。
2. 買う条件は `推定確率 * オッズ - 1 > 0` を満たすこと。
3. 根拠が薄い馬券、直前オッズで期待値が消えた馬券、資金配分が過大になる馬券は見送る。
4. 1点ごとの推奨額は控えめにし、ケリー基準をそのまま使わず縮小する。
5. 的中率ではなく、長期の回収率と最大ドローダウンを管理する。

## 使い方

1. `data/manual_bets.csv` に候補馬券を入力する。
2. `probability` には自分の推定的中確率を小数で入れる。例: 18% なら `0.18`。
3. `odds` には購入直前のオッズを入れる。
4. `stake` は仮の購入額。空欄ならスクリプトが資金配分から推奨額を出す。
5. 以下を実行する。

```powershell
python src/expected_value.py --input data/manual_bets.csv --bankroll 10000 --kelly-scale 0.25
```

結果は `outputs/bets_recommended.csv` に出力されます。

## 判定ルール

- `ev_per_yen`: 1円あたり期待値。`0.10` なら理論上10%プラス。
- `break_even_probability`: 損益分岐的中率。`1 / odds`。
- `probability_edge`: 推定確率と損益分岐確率の差。
- `kelly_fraction`: フルケリー比率。
- `recommended_stake`: `bankroll * kelly_fraction * kelly_scale` を上限つきで丸めた推奨額。

## 注意

競馬は控除率が高く、短期では分散が大きいです。この基盤は利益を保証するものではありません。期待値がない候補は買わないことも実行の一部です。
